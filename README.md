# NEXWEB

תיק עבודות של **NEXWEB**, סטודיו לדפי נחיתה ואתרים בעברית.  
שבעה דפים סטטיים: עמוד הבית, ושישה דפי דמו לעסקים בדיוניים.

הדפים מימין לשמאל (`lang="he"` `dir="rtl"`). הטפסים רצים בדפדפן בלבד ומציגים מסך הצלחה. שום דבר לא נשלח לשרת.

## תצוגה מקומית

אין שלב בנייה. הנתיבים יחסיים, כך שהאתר עובד גם מתיקיית משנה כמו `/nexweb-portfolio/`. מכל תיקייה שמגישה קבצים סטטיים:

```bash
python3 -m http.server 41731
```

ואז לפתוח [http://127.0.0.1:41731](http://127.0.0.1:41731).

## העלאה

האתר הוא קבצי HTML, CSS, JS ותמונות. אפשר להעלות את התיקייה כמו שהיא.

**Vercel:** לייבא את הריפו, לבחור Framework: Other, ולהשאיר את פקודת הבנייה ריקה. `vercel.json` כבר מסמן שאין build. תיקיית הפלט היא שורש הפרויקט.

**Netlify / GitHub Pages / כל אחסון סטטי:** לפרסם את השורש. `index.html` הוא עמוד הבית.

## שינוי שם הסטודיו

השם מופיע בשני מקומות שכדאי לעדכן יחד:

1. `STUDIO_NAME` בקובץ `js/config.js` — הלוגו, הכותרות בדפדפן, והקרדיט «נבנה כדוגמה על ידי» בכל דפי הדמו.
2. תגית `<title>` ותגיות ה־meta ב־`index.html` — כדי שתצוגה מקדימה של הקישור (בלי JavaScript) תישאר נכונה.

מספרי הטלפון והוואטסאפ בכל הדפים הם מספרי הדגמה (`050-000-00XX`).

## תמונות

התמונות הורדו מ־Unsplash ושמורות בתיקייה `images/`, כדי שהאתר לא יישבר אם קישור חיצוני ייעלם. הן להמחשה בלבד, כמו השמות, המחירים וההמלצות.
